# Sistem Pencatatan Hasil Panen

## Deskripsi

Sistem Pencatatan Hasil Panen merupakan program Python sederhana yang digunakan untuk menghitung total hasil panen berdasarkan jumlah hasil panen dan harga per kilogram. Program ini juga memiliki fitur perhitungan diskon untuk mengetahui nilai diskon dan total setelah diskon.

## Cara Menjalankan Program

1. Pastikan Python telah terinstal.
2. Clone repository GitHub.
3. Masuk ke folder `sistem-panen-nurmadani`.
4. Jalankan program dengan perintah:

```bash
python panen.py
